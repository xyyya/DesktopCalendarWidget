一款基于 C# WPF 开发的轻量级桌面日历与待办事项管理小组件。

## 🌟 主要特性
- 📅 **直观日历**：带有每日任务小蓝点标记，完成所有任务后蓝点自动消除，转为绿点。
-  **待办管理**：支持单次任务与周期重复提醒（天/周/月/年）。
- 🔝 **打卡沉底**：勾选已完成任务后，自动排序下沉至列表末尾。
- 📌 **边缘隐藏**：支持靠屏幕边缘自动隐藏，鼠标悬停时唤出。
- 📜 **打卡历史**：内嵌抽屉查看历史打卡记录，支持一键撤回。

## 🛠️ 技术栈
- C# / WPF (.NET)
- System.Text.Json (数据持久化)
